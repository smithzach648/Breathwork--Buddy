## Our reproducible noise experiment

Let x[n] be the unchanged 4B `maskingSteps('brown', rate, 2^20, xorshift32(seed))` output. That original generator applies its 60 Hz low rolloff / 1400 Hz high rolloff / power-two contour, circular bounded energy correction and ≤0.1 RMS / ≤0.5 peak calibration. Importing the original function keeps this source implementation unchanged.

At absolute session time t = n / sampleRate, θ = 2π sweepHz t + phase. Delay L = d(1 + depth sin θ); delay R = d(1 + depth sin(θ + width π/2)). Each output is `(1 − mix)x[n] + mix x[n − delay × sampleRate]`, multiplied by the requested noise level. Fractional samples use linear interpolation into the circular source. This is a feed-forward comb, with no feedback and no left/right amplitude panning. Width zero is centered; depth zero freezes the base delay; mix zero/static Warm bypasses delayed content. The same t also determines integrated carrier phase and optional AM phase. This is an explicit common timebase, not a claim of phase locking to a neurological signal.

The delay read is mathematically equivalent to a bounded periodic delay line. Because no feedback/filter history exists after the source generator, arbitrary seek reconstructs the same noise and carrier state without minutes of pre-roll. The source loop lasts 2^20/rate seconds. It may become recognizable during long listening; source-length alternatives are a future decision, not an undisclosed change to the control.

Septon also has same-ear nonadjacent 8 Hz differences and cross-ear differences including 0/4/8/12 Hz in addition to designated pair assignments. Layered reference same-ear spacings are 51/47/98 Hz; Expansion L spacings 51/47/98, R 53/45/98 Hz. Such interactions are real consequences of mixing carriers; no claim that only three beat phenomena exist. Mono downmix loses binaural ear separation.

The original 4B control preserves source function/length, spectral contour, default noise/tone levels, 0.14 tone multiplier, normalized pair gains, 30-minute entry/steady/return allocation and fixed 0.25 trim. Its seeded sample realization is not an original production random buffer capture. Analytical sine processing and a non-oversampled identity-region ceiling are independently measured against native nodes; we do not call the whole render byte-equivalent to 4B.

Export determinism requires the same engine version, recipe, seed, sample rate, sample-aligned start/duration and mode. Repeat renders are bit-identical in the tested runtime; cross-engine floating-point transcendental differences are possible. Stereo 16-bit PCM quantization is not the internal Float32 waveform. Reports record the relevant metadata and measured spectrum resolution.
